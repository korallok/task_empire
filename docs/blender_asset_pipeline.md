# Пайплайн 3D-зданий Task Empire

Город остаётся изометрической 2D-сценой, но здания создаются в Blender и
рендерятся с прозрачным фоном. Это даёт объёмное изображение уровня мобильных
стратегий без тяжёлого 3D-движка внутри Flutter.

## 1. Подготовка Blender

1. Установите Blender.
2. Сохраните `.blend`-файл внутри репозитория, например:
   `art/task_empire_city.blend`.
3. Считайте одну клетку города равной одной единице Blender.
4. Центр логического footprint каждого здания должен находиться в `(0, 0, 0)`,
   а нижняя плоскость — в `Z = 0`.
5. Не перемещайте камеру и основной свет между зданиями.

Скрипт `tool/blender/export_city_assets.py` автоматически создаёт и настраивает:

- ортографическую камеру с фиксированным изометрическим углом;
- основной мягкий источник света;
- прозрачный холст 1024×1024;
- одинаковые настройки цвета и рендера.

## 2. Имена коллекций

Каждый экспортируемый вариант здания хранится в отдельной Blender Collection:

```text
EXPORT_town_hall_level_1
EXPORT_town_hall_level_2
EXPORT_town_hall_level_3
EXPORT_market_level_1
EXPORT_market_level_2
EXPORT_market_level_3
EXPORT_house_level_1
EXPORT_library_level_1
EXPORT_workshop_level_1
EXPORT_tower_level_1
EXPORT_garden_level_1
```

Во время экспорта скрипт последовательно скрывает остальные `EXPORT_`
коллекции. Камера, свет и общие вспомогательные объекты не должны находиться
внутри этих коллекций.

## 3. Визуальный стиль

- Используйте крупные формы и умеренное количество мелких деталей.
- Делайте силуэт здания узнаваемым даже на размере 80–140 пикселей.
- Свет идёт сверху-слева, тень — вправо-вниз.
- Материалы должны быть матовыми, с немного усиленной насыщенностью.
- Крыши и интерактивные элементы желательно выделять цветом.
- Каждый новый уровень должен менять силуэт, а не только добавлять декор.
- Добавляйте мягкую полупрозрачную тень в экспортируемую коллекцию.

Зафиксированные технические параметры пайплайна:

```text
Camera: orthographic
Location: (9.5, -9.5, 8.0)
Target: (0.0, 0.0, 1.1)
Orthographic scale: 5.8
Key light: area / disk, (-6.0, -7.5, 11.0), 1100 W, size 5.5
Canvas: 1024 × 1024, RGBA, transparent
View transform: AgX / Medium High Contrast
```

Не меняйте эти параметры между зданиями. Если визуальное направление требует
другой камеры или света, обновите скрипт и перерендерите весь набор целиком.

Не копируйте модели, текстуры или интерфейс существующих игр. Можно использовать
их только как ориентир по читаемости и степени стилизации.

## 4. Footprint и origin

Логическая площадь задаётся в `building_definitions`, а не вычисляется по
прозрачным пикселям изображения:

```text
Ратуша       4 × 4
Дом          2 × 2
Библиотека   3 × 3
Мастерская   3 × 2
Рынок        3 × 3
Башня        2 × 2
Сад          2 × 2
```

- Геометрия может выходить за footprint вверх, но основание не должно выходить
  за его границы.
- Origin всех уровней одного здания должен совпадать.
- Повороты выполняются игровой логикой с шагом 90°. Для несимметричных зданий
  силуэт должен оставаться читаемым после смены footprint 3×2 ↔ 2×3.
- Экспортируемая тень не должна визуально менять точку основания.

## 5. Экспорт

В Blender откройте рабочее пространство **Scripting**, загрузите и запустите:

```text
tool/blender/export_city_assets.py
```

Либо выполните из корня проекта:

```powershell
blender --background art/task_empire_city.blend `
  --python tool/blender/export_city_assets.py
```

PNG-файлы появятся в `assets/city/buildings`. Flutter автоматически обнаружит
их и заменит соответствующие векторные здания. Lossless WebP с тем же именем
имеет приоритет над PNG.

## 6. Проверка в приложении

```powershell
flutter run -d chrome -t tool/design_preview.dart
```

Проверьте:

- основание здания совпадает с центром клетки;
- здание не прыгает при переходе между уровнями;
- прозрачные поля вокруг всех рендеров одинаковы;
- тень не обрезается;
- соседние здания перекрываются в правильном порядке.
- зелёный/красный preview точно покрывает логический footprint;
- 90° и 270° меняют местами ширину и высоту footprint;
- высота спрайта не влияет на depth sorting — используется дальняя точка
  основания.

Размер и точку привязки можно скорректировать в
`lib/features/city/presentation/city_building_art.dart`.
